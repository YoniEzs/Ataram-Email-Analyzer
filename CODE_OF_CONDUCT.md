# Code of Conduct

We want participation in this project to be safe, respectful and useful.

## Expected behavior

- Be considerate, specific and constructive.
- Welcome people with different backgrounds and experience levels.
- Discuss the work and evidence, not personal characteristics.
- Protect private data, credentials and real email samples.
- Respect responsible-disclosure boundaries.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, doxxing, sharing
credentials or victim data, and deliberately disruptive behavior are not
accepted in project spaces.

## Enforcement

Report conduct concerns privately through the maintainer's GitHub profile or,
when the concern is security-related, a private security advisory. Maintainers
may edit or remove content, close interactions, temporarily restrict
participation or permanently ban participants. Reports will be handled as
confidentially as practical.

This policy applies to repository discussions, issues, pull requests and other
spaces where someone represents the project.
