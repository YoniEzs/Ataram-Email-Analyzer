Ataram Email Analyzer

Phishing triage that runs on your machine.
Drop an .eml or .msg file, get the analyst checklist in seconds.

Experimental v0.1.0-rc1 — feedback welcome

Your email never leaves your computer. Analysis is local; the only optional network traffic is DNS/RDAP lookups of header-derived IPs and domains, and every one of them can be switched off for fully offline work.

Download

What it gives you

The triage checklist, extracted

Sender, subject, recipients, timestamps, sending server IP, reverse DNS and Reply-To — pulled out as structured artifacts with a copy-for-ticket export.

An honest trust model

Every value is labelled: read from the (forgeable) file, computed from it, or verified against live DNS. Nothing an attacker can fake affects the risk score.

Free enrichment, no API keys

Forward-confirmed reverse DNS, ASN and BGP prefix via Team Cymru, registry and abuse contact via RDAP. AbuseIPDB and VirusTotal plug in if you bring keys.

Attachment & URL checks

Magic bytes, double extensions, archive inspection without extraction, YARA rules, homograph domains, and displayed-link mismatches.

Install

1. Download AtaramEmailAnalyzer-v0.1.0-rc1-windows-x64.zip from the Releases page
2. Extract anywhere and run AtaramEmailAnalyzer.exe
3. Your browser opens at http://127.0.0.1:8321 — drop an .eml file in

The binaries are unsigned, so SmartScreen will warn on first run: choose More info → Run anyway. Verify your download against SHA256SUMS.txt on the release page — the build is reproducible from the open source.

curl -LO https://github.com/YoniEzs/Ataram-Email-Analyzer/releases/download/v0.1.0-rc1/AtaramEmailAnalyzer-v0.1.0-rc1-macos-arm64.zip
unzip AtaramEmailAnalyzer-v0.1.0-rc1-macos-arm64.zip
./AtaramEmailAnalyzer/AtaramEmailAnalyzer

Unsigned build: on first run, right-click the binary and choose Open, or allow it under System Settings → Privacy & Security.

curl -LO https://github.com/YoniEzs/Ataram-Email-Analyzer/releases/download/v0.1.0-rc1/AtaramEmailAnalyzer-v0.1.0-rc1-linux-x64.zip
unzip AtaramEmailAnalyzer-v0.1.0-rc1-linux-x64.zip
./AtaramEmailAnalyzer/AtaramEmailAnalyzer

Opens your browser at http://127.0.0.1:8321. Headless? Set ATARAM_NO_BROWSER=1 and browse to the printed URL.

curl -LO https://raw.githubusercontent.com/YoniEzs/Ataram-Email-Analyzer/main/docker-compose.release.yml
ATARAM_VERSION=0.1.0-rc1 docker compose -f docker-compose.release.yml up

Then open http://localhost:3000. The full stack — hardened containers, Redis-backed caching — for teams or always-on use. ATARAM_VERSION is required while only a release candidate exists: the :latest image tag is published for stable releases only.

# Not yet available — planned for the stable v0.1.0 release
pipx install ataram-email-analyzer
